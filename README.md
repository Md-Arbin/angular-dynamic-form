# 🧩 Dynamic Form Renderer (Angular 14)

A reusable **Dynamic Form Renderer** built with **Angular 14**.  
It dynamically generates forms based on a configurable **JSON schema** — supporting multiple input types, validation, and flexible schema-based rendering.

---

## 🚀 Features

- Dynamic form rendering from JSON schema  
- Supports:
  - Text, Textarea  
  - Date picker  
  - Dropdown (single select)  
  - Multiselect  
  - Checkbox  
- Validation (required, pattern-based, etc.)  
- Displays validation messages clearly  
- Submits and displays structured form data  
- Reusable component — plug any schema

---

## 🛠️ Tech Stack

- **Angular 14.2.13**
- **TypeScript 4.6.4**
- **Node 16**
- **@types/node 16.11.68**
- **Reactive Forms**
